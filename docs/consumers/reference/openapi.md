# :material-code-json: Live demo OpenAPI

The document the [demo instance](https://fastgeoapi.fly.dev/geoapi) is
serving right now — generated by pygeoapi and augmented with
fastgeoapi's security schemes, which is what makes the authentication
visible to a client.

<!-- Swagger UI is loaded from its CDN rather than through a plugin.
     `mkdocs-swagger-ui-tag` has no Zensical equivalent yet, and this
     page was its only caller: one custom element against a URL. Doing
     it here keeps the page working and costs one script tag. -->

<link rel="stylesheet" href="https://unpkg.com/swagger-ui-dist@5/swagger-ui.css" />
<div id="swagger-ui"></div>
<script src="https://unpkg.com/swagger-ui-dist@5/swagger-ui-bundle.js" crossorigin></script>
<script>
  window.addEventListener("load", () => {
    window.SwaggerUIBundle({
      url: "https://fastgeoapi.fly.dev/geoapi/openapi?f=json",
      dom_id: "#swagger-ui",
      docExpansion: "none",
      filter: "",
      syntaxHighlight: { theme: "monokai" },
    });
  });
</script>
