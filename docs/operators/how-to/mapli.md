# :material-map-outline: mapli provider

The mapli provider is an OGC API - Maps provider. It draws PNG maps of a
PMTiles archive of vector or raster tiles, using
[mapli](https://geobeyond.github.io/mapli/), a Python library that renders
MapLibre styles with MapLibre Native. The archive is read in place, from a
local path, an https URL or a bucket, in the same way as the
[PMTiles provider](pmtiles.md).

## Installation

mapli is published on PyPI as Linux wheels for x86_64 and aarch64. They need
glibc 2.34 or later. Install fastgeoapi with the `mapli` and `pmtiles` extras.
The provider needs the `pmtiles` extra to read the archive:

```shell
pip install "fastgeoapi[mapli,pmtiles]"
```

mapli draws through an OpenGL (EGL) context. A GPU is not required: Mesa's
llvmpipe software renderer is used when none is present. On Debian and Ubuntu,
the system needs:

```shell
apt-get install libegl1 libegl-mesa0 libgl1-mesa-dri libcurl4t64 xvfb
```

EGL also needs a display. On a desktop machine, the existing display is used.
On a server or in a container, start an X virtual framebuffer before the server
and point `DISPLAY` at it:

```shell
Xvfb :99 -screen 0 1280x1024x24 -nolisten tcp &
export DISPLAY=:99
```

On machines that expose a GPU device that Xvfb cannot use, set
`LIBGL_ALWAYS_SOFTWARE=1` so that Mesa uses its software renderer. The mapli
[system requirements](https://geobeyond.github.io/mapli/user-guide/system-requirements/)
page has more detail.

## Enabling the provider

Add a provider of type `map` to a collection:

```yaml
providers:
  - type: map
    name: app.provider.mapli.MapliMapProvider
    data: s3://my-bucket/tiles/roads.pmtiles
    storage_crs: http://www.opengis.net/def/crs/EPSG/0/3857
    store_options:
      endpoint: fly.storage.tigris.dev
      region: auto
    options:
      default_background_color: "#f8f4f0"
      max_size: 2048
    format:
      name: png
      mimetype: image/png
```

- `data` is the archive: a local path, an `https://` URL or a bucket key.
  `store_options` holds the bucket settings, as described in the PMTiles guide.
- `storage_crs` must be EPSG:3857, because maps are drawn in Web Mercator only.

The collection then serves `/collections/{collectionId}/map`, and one
`/collections/{collectionId}/styles/{styleId}/map` route for each configured
style.

## Configuration

The provider's own settings go under `options`:

| Option                                | Default                                                          | Meaning                                                                                                                                                          |
| ------------------------------------- | ---------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `styles`                              | none                                                             | Style names mapped to MapLibre styles: a style URL, or a style written inline. If not provided, a default style is generated by the provider (see next section). |
| `default_style`                       | none                                                             | Name of the default style. If provided, it must be one of `styles`.                                                                                              |
| `default_background_color`            | `#ffffff`                                                        | Background of the generated style for vector and raster archives.                                                                                                |
| `default_vector_colors`               | `#e15759`, `#4e79a7`, `#59a14f`, `#f28e2b`, `#76b7b2`, `#b07aa1` | A list of colors to alternate when generating default styles for collections of type vector.                                                                     |
| `default_hillshade_background_color`  | `#f2efe9`                                                        | Background of the generated style for an elevation archive.                                                                                                      |
| `dem`                                 | none                                                             | If provided, must be either `terrarium` or `mapbox`, for a raster archive of elevations. The generated style shades the relief.                                  |
| `max_size`                            | 2048                                                             | The largest `width` and `height` a request may ask for.                                                                                                          |
| `max_image_width`, `max_image_height` | `max_size`                                                       | The largest `width` and `height`, set separately.                                                                                                                |
| `min_image_width`, `min_image_height` | 10                                                               | The smallest `width` and `height`.                                                                                                                               |
| `num_workers`                         | 1                                                                | Number of rendering threads used by mapli.                                                                                                                       |
| `max_renderers_per_worker`            | 4                                                                | Renderers each thread keeps. Each renderer holds its own GL context and tile cache.                                                                              |
| `data_url`                            | none                                                             | An https address of the archive that mapli reads directly. It is used only when the range cache is off.                                                          |
| `range_cache`                         | true                                                             | Read a bucket archive through the range cache. `false` reads each range from the bucket.                                                                         |

### Styles

When the provider configuration does not include the `styles` key, maps are drawn with a simple autogenerated style,
depending on the type of data being read:

- **Vector layers** are drawn in one of `default_vector_colors`.
- **Rasters** are drawn as a simple raster layer.
- **An elevation archive with `dem`:** the relief is drawn as a hillshade.

A style in `styles` is either the URL of a MapLibre style document, which mapli
fetches itself, or a style written inline in the configuration. inline styles
can declare their source using the special keyword `dataset` (and thus without providing
the actual `url` of the source) in order to have the provider fill in with the correct URL,
as per its own configuration. Example:

```yaml
options:
  styles:
    roads:
      version: 8
      sources:
        dataset:
          type: vector
      layers:
        - id: roads
          type: line
          source: dataset
          source-layer: roads
          paint:
            line-color: "#4e79a7"
    basemap: https://example.org/styles/basemap.json
  default_style: roads
```

Maps are transparent unless the request passes `transparent=false`. A
transparent map hides the layers of type `background`. A style with labels
needs a `glyphs` URL that mapli can reach.

## Reading data from a bucket

When the fastgeoapi range cache is turned on, which is the default, the
mapli provider reads through the range cache described in the [PMTiles guide](pmtiles.md#range-cache), so bytes
read once are reused until they are evicted or the archive changes.

When the range cache is disabled, there is no caching and the mapli provider reads straight from the bucket.
If the archive is public, the `data_url` key can give its https address instead, and mapli then reads the
archive from that address.

A private bucket, read through the range cache. The credentials come from the
standard environment variables, as described in
[Config from cloud object storage](cloud-config.md):

```yaml
- type: map
  name: app.provider.mapli.MapliMapProvider
  data: s3://my-bucket/tiles/roads.pmtiles
  storage_crs: http://www.opengis.net/def/crs/EPSG/0/3857
  store_options:
    region: eu-west-1
```

A public bucket on an S3-compatible service. `skip_signature` sends unsigned
requests, so no credentials are needed:

```yaml
- type: map
  name: app.provider.mapli.MapliMapProvider
  data: s3://my-public-bucket/tiles/roads.pmtiles
  storage_crs: http://www.opengis.net/def/crs/EPSG/0/3857
  store_options:
    endpoint: fly.storage.tigris.dev
    region: auto
    url_style: vhost
    skip_signature: true
```

A public bucket with the range cache disabled. mapli reads the archive at its
`data_url`:

```yaml
- type: map
  name: app.provider.mapli.MapliMapProvider
  data: s3://my-public-bucket/tiles/roads.pmtiles
  storage_crs: http://www.opengis.net/def/crs/EPSG/0/3857
  store_options:
    endpoint: fly.storage.tigris.dev
    region: auto
    url_style: vhost
    skip_signature: true
  options:
    range_cache: false
    data_url: https://my-public-bucket.fly.storage.tigris.dev/tiles/roads.pmtiles
```

!!! tip "Technical details"
The fastgeoapi mapli provider registers a scheme handler for URLs of the
form `fastgeoapi://<source>/<version>`, and the styles point mapli at those URLs.
When mapli reads the archive, the handler serves the requested bytes through
the fastgeoapi store, with the collection's `store_options`. The URLs contain
neither the bucket's location nor any credentials.

    Read more about custom scheme handlers at the [mapli docs](https://geobeyond.github.io/mapli/user-guide/custom-url-schemes/).

## Request parameters

A map request can pass `bbox`, `bbox-crs`, `crs`, `width`, `height`,
`transparent` and `f`, as in OGC API - Maps.

- **`crs`**, when given, must be the EPSG:3857 URI.
- **`f`** takes `png`. `f=html` also returns the PNG.
- **Errors:** an unknown style answers 400. An archive of AVIF tiles answers 500
  with "map source not drawable".
